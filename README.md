# Breast-Cancer-Prediction-ML
A production-grade, object-oriented Machine Learning pipeline for breast cancer classification (SDG 3: Good Health and Well-being). Features scikit-learn pipelines to eliminate data leakage, nested 5-fold cross-validation for unbiased tuning, permutation importance for explainability, and joblib model persistence (ROC-AUC: 0.9939, Recall: 97.22%).
